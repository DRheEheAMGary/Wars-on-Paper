# 性能与压测

## 运行

```bash
npm run bench                         # 16 玩家 / 240 城 / 15 秒
node tools/bench.mjs --players 32 --seconds 20
```

bench 会启动一个进程内服务器，连接 N 个 WebSocket 客户端，自动建房/加入/开局，
持续发送招募与派兵指令，然后校验：

- 同一 tick 下所有客户端的城市归属/驻军/军队哈希是否一致（状态漂移）
- 快照到达间隔（p50 / p95）
- 指令从发送到反映在快照里的延迟（p95）
- 是否发生占领（证明战斗链路在负载下工作）
- 同配置下独立模拟 600 tick 的 p95

## 最近结果（2026-10-19，本机）

| 玩家 | 城市 | tick 数 | 漂移 | 快照间隔 p95 | 指令延迟 p95 | 模拟 tick p95 |
| --- | --- | --- | --- | --- | --- | --- |
| 8 | 240 | 79 | 0 | 102.8ms | 101.0ms | 0.037ms |
| 16 | 240 | 148 | 0 | 103.5ms | 97.5ms | 0.028ms |
| 32 | 240 | 148 | 0 | 103.6ms | 97.3ms | 0.046ms |

验收目标（M4）：16 客户端整局无漂移、32 人 / 240 城模拟 tick p95 < 2ms，均满足。
