# 纸上谈兵 / Wars on Paper

网页端实时领土争夺游戏：地图由上百个城市节点组成，每座城市拥有一块边缘随机的领土并铺满全图；玩家占领城市吞并领土，在 10–20 分钟内以城市数量与领土占比决出胜负。

- **单机**：与 1–7 个 AI 抢先扩张、争夺城市。
- **多人**：单房间 16–32 人在线乱斗。
- **技术**：免编译 —— 原生 ES Module + Canvas 2D + Node.js，改完刷新即生效。

## 启动方式

需要 Node.js ≥ 20（当前无构建步骤，`npm install` 仅安装 `ws`，多人模式 M4 才用到）。

```bash
npm install          # 可选，仅安装 ws（唯一运行依赖）
npm run dev          # 开发服务器 + 热刷新，浏览器打开 http://localhost:8787
npm run server       # 静态资源 + 多人 WebSocket 服务器（M4 起提供联机）
npm test             # node --test
```

开发服务器默认只监听 `127.0.0.1:8787`（8080 常被其他工具占用），可用 `PORT=8788 npm run dev` 更换端口。

## 多人游戏（M4）

```bash
npm run dev
# 浏览器打开 http://localhost:8787/ → 多人乱斗
# 两个浏览器（或不同窗口）分别建房/加入 → 房主开始
```

房间码形如 `QW5ZN`；刷新页面会用当前标签页的 token 自动重连。最多 32 人，240 城地图默认支持 32 个出生点。压测：`npm run bench`（见 `docs/PERF.md`）。

## 单人游戏（M3）

```bash
npm run dev
# 浏览器打开 http://localhost:8787/ → 单人游戏
```

也支持直接访问 `/game.html?seed=123&cities=160&ai=2&difficulty=normal&minutes=10` 指定全部参数。对局中：**单击城市选中**，左侧「派兵数量」滑条决定这次派出多少兵，然后**从选中的城市拖到目标城市**：拖到自己的城市可跨任意距离调兵，攻击其他城市则只能是相邻或渡海城市。顶栏可暂停与加速。

## 地图原型（M1）

```bash
npm run dev
# 浏览器打开 http://localhost:8787/tools/mapdebug.html
```

可切换种子与城市数（60 / 100 / 160 / 240 / 360）、显示邻接线、悬停查看城市信息；主菜单页脚也有入口。同一种子始终生成同一张地图。地图为大长方形世界：海洋占 70%，2–4 块独立生成的大陆形状与位置各不相同，空旷海域会生成 1–3 座小岛，海岸线由城市边缘构成，没有湖泊；扩大世界不会改变陆地总面积。
